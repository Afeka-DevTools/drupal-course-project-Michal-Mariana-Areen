### מה עשינו
בפרויקט זה הקמנו סביבת פיתוח מקומית עבור מערכת ניהול התוכן Drupal, תוך שימוש בארכיטקטורת קונטיינרים (Containers) מבודדת דרך Docker. העבודה המשותפת שלנו התחלקה למספר שלבים טכניים:

1. **ניהול גרסאות וסנכרון:** משיכת קוד הפרויקט וקבצי הגיבוי המעודכנים ממאגר ה-Git המשותף.
2. **הקמת תשתית וירטואלית:** הרצת קונטיינרים מקונפגים מראש עבור האפליקציה של Drupal ועבור מסד נתונים מסוג PostgreSQL.
3. **אוטומציית שחזור:** הפעלת סקריפט שחזור אוטומטי (`restore.sh`) אשר מקים את הרשת הפנימית בין הקונטיינרים, טוען את קובץ הגיבוי אל תוך מסד הנתונים, ומשחזר את מערכת הקבצים (Volumes) של האתר.
4. **קונפיגורציה והזנת תוכן:** קישור מוצלח בין Drupal למסד הנתונים, הגדרת הרשאות ומשתמשים (מנהל ראשי ומשתמשי צוות), והזנת מושגים ותוכן ראשוני אל תוך המערכת.
