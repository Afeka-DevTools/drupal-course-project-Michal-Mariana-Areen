# פרויקט קורס - סביבת Drupal ב-Docker

ברוכים הבאים לפרויקט המסכם שלנו! פרויקט זה מדגים כיצד להקים, לנהל, לגבות ולשחזר סביבת Web מלאה המבוססת על מערכת ניהול התוכן Drupal ומסד נתונים MySQL, באמצעות קונטיינרים של Docker. הכל מנוהל בצורה אוטומטית בעזרת סקריפטים של Bash.

## b. מה נדרשנו לעשות
במסגרת המטלה נדרשנו לבצע את הפעולות הבאות:
1. להקים סביבת Docker הכוללת רשת וירטואלית פנימית.
2. להרים שני קונטיינרים: שרת ווב (Drupal) ושרת בסיס נתונים (MySQL), ולקשר ביניהם.
3. להגדיר את אתר ה-Drupal, לחבר אותו ל-Database וליצור משתמשים בעלי הרשאות ניהול (Administrator) עבור כל חברות הצוות.
4. להוסיף סוג תוכן חדש (Content Type) בשם "Course Term" ולהזין אליו תוכן ראשוני מהקורס.
5. לייצא גיבוי מלא של בסיס הנתונים (Dump) לקובץ לוקאלי.
6. לכתוב סקריפטים (Bash Scripts) לאוטומציה מלאה של התהליך: Setup, Backup, Restore, ו-Cleanup.

---

## c. מה עשינו
* **הקמת תשתית:** יצרנו רשת ייעודית בשם `drupal-net` והרמנו קונטיינר של MySQL עם הגדרות משתמש וסיסמה מאובטחות (דרך Environment Variables), יחד עם קונטיינר של Drupal שחושף את פורט 8080 למחשב המארח.
* **הגדרת המערכת:** נכנסנו לממשק ההתקנה של Drupal דרך הדפדפן וחיברנו אותו בהצלחה ל-MySQL.
* **ניהול משתמשים ותוכן:** יצרנו פרופילי Administrator עבור מיכל, מריאנה וארין. לאחר מכן, הוספנו סוג תוכן בשם `Course Term` ויצרנו בו מושג ראשון (Docker) עם הסבר קצר.
* **גיבוי (Backup):** השתמשנו בכלי `mysqldump` כדי לשלוף את כל הנתונים מקונטיינר ה-MySQL וליצור את הקובץ `my-drupal.backup.sql`. הוספנו את הדגל `--set-gtid-purged=OFF` כדי למנוע שגיאות סנכרון (GTID) בשחזור.
* **אוטומציה:** ארזנו את כל הפקודות לתוך 4 קובצי סקריפט `.sh` קלים לשימוש.

## e. מדריך Step-By-Step למשתמש
מדריך זה ילווה אותך צעד אחר צעד משלב הורדת הקוד ועד לניקוי מלא של המכונה שלך. הקפד להריץ את הפקודות מתוך טרמינל תומך (כגון Git Bash, WSL, או PowerShell עם תמיכה ב-Bash) וודא ש-Docker Desktop פתוח ופועל ברקע.

### שלב 1: שכפול המאגר (Clone)
פתח את הטרמינל, נווט לתיקייה בה תרצה לשמור את הפרויקט והרץ:
```bash
git clone [https://github.com/michalgabovich1-boop/drupal-course-project-Michal-Mariana-Areen.git](https://github.com/michalgabovich1-boop/drupal-course-project-Michal-Mariana-Areen.git)
cd drupal-course-project-Michal-Mariana-Areen
```

### שלב 2: הקמת סביבת העבודה (Setup)
הרצת הסקריפט הבא תיצור את רשת ה-Docker המקומית, תפעיל את מסד הנתונים, ותפעיל את אתר ה-Drupal.
```bash
bash setup.sh
```
*המתן מספר שניות כדי לאפשר ל-MySQL לסיים את תהליך העלייה שלו.*

### שלב 3: פתיחת האתר והגדרה ראשונית
פתח את הדפדפן שלך וגלוש לכתובת:
`http://localhost:8080`
*(בשלב זה תראה את מסך ההתקנה הראשוני של דרופל. אין צורך לעבור אותו ידנית, כיוון שיש לנו גיבוי מוכן מראש שיעשה זאת עבורנו).*

### שלב 4: שחזור בסיס הנתונים (Restore)
כדי לייבא את כל המידע שכבר הכנו (ההגדרות, המשתמשים והתוכן), הרץ את פקודת השחזור. סקריפט זה לוקח את הקובץ `my-drupal.backup.sql` ומזריק אותו ישירות לתוך קונטיינר ה-MySQL:
```bash
bash restore.sh
```
כעת, אם תרענן את הדף בדפדפן (`http://localhost:8080`), תראה שהאתר מוגדר במלואו! תוכל להתחבר עם המשתמשים שנוצרו ולראות את התוכן שהזנו.

### שלב 5: גיבוי נתונים חדשים (Backup) - אופציונלי
אם הוספת תוכן חדש לאתר ואתה מעוניין לשמור אותו, הרץ את הסקריפט הבא. הוא יידרוס את קובץ הגיבוי הקיים בתיקייה וישמור את הנתונים העדכניים:
```bash
bash backup.sh
```

### שלב 6: ניקוי סביבת העבודה (Cleanup)
בסיום העבודה, כדי לא להשאיר קבצי זבל או קונטיינרים רצים על מכונת ה-Linux/Windows שלך, הרץ את פקודת הניקוי. סקריפט זה יעצור וימחק את הקונטיינרים, ימחק את הרשת הוירטואלית, ויסיר את האימאג'ים של שתי המערכות:
```bash
bash cleanup.sh
```
לאחר מכן, ה-Docker שלך נקי לחלוטין משאריות הפרויקט.
