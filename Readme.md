## מה נדרשנו לעשות
* הקמת אתר Drupal המכיל את מושגי הקורס, תוך שימוש ב-Docker.
* שמירת נתוני האתר בבסיס נתונים PostgreSQL.
* אוטומציה של תהליכי ההקמה, הגיבוי, השחזור והניקוי באמצעות סקריפטים.

### מה עשינו
בפרויקט זה הקמנו סביבת פיתוח מקומית עבור מערכת ניהול התוכן Drupal, תוך שימוש בארכיטקטורת קונטיינרים (Containers) דרך Docker. העבודה המשותפת שלנו התחלקה למספר שלבים טכניים:

1. **ניהול גרסאות וסנכרון:** משיכת קוד הפרויקט וקבצי הגיבוי המעודכנים ממאגר ה-Git המשותף.
2. **הקמת תשתית וירטואלית:** הרצת קונטיינרים מקונפגים מראש עבור האפליקציה של דרופל ועבור מסד נתונים מסוג PostgreSQL.
3. **אוטומציית שחזור:** הפעלת סקריפט שחזור אוטומטי (`restore.sh`) אשר מקים את הרשת הפנימית בין הקונטיינרים, טוען את קובץ הגיבוי אל תוך מסד הנתונים, ומשחזר את מערכת הקבצים (Volumes).

## מדריך Step-By-Step למשתמש
כדי להריץ את הפרויקט על המחשב המקומי, יש לעקוב אחר השלבים הבאים. טרם תחילת התהליך, ודאו שתוכנת Docker Desktop מותקנת ופועלת ברקע (Engine running).

### שלב 1: משיכת קוד הפרויקט (Clone / Pull)
פתחו את הטרמינל במחשב / VS Code ומשכו את הקוד ממאגר ה-Git:
```bash
git clone [https://github.com/Afeka-DevTools/drupal-course-project-Michal-Mariana-Areen](https://github.com/Afeka-DevTools/drupal-course-project-Michal-Mariana-Areen)
cd drupal-course-project-Michal-Mariana-Areen
```

### שלב 2: הרצת תהליך השחזור וההקמה האוטומטי
כדי להקים את הסביבה ולשחזר את כל הנתונים (מסד נתונים + קבצים), הריצו את הפקודות הבאות בטרמינל:
```bash
chmod +x restore.sh setup.sh backup.sh cleanup.sh
./setup.sh
./restore.sh
```
*הסקריפטים יקימו את הרשת, יפעילו את הקונטיינרים, ייבאו את מסד הנתונים ויחלצו את קבצי העיצוב.*

### שלב 3: גישה לאתר ובדיקתו
לאחר סיום הרצת הסקריפטים, פתחו את הדפדפן וגשו לכתובת:
[http://localhost:8080](http://localhost:8080)

ניתן להתחבר למערכת עם פרטי המשתמשים המופיעים בראש הקובץ, לדוגמה מנהל המערכת:
* **שם משתמש:** `demoadmin`
* **סיסמה:** `secretpass`

### שלב 4: כיבוי וניקוי הסביבה (Cleanup)
בסיום העבודה, יש לנקות את סביבת העבודה. סקריפט הניקוי יכבה וימחק את הקונטיינרים וה-Volumes שנוצרו, וישאיר את המכונה נקייה:
```bash
./cleanup.sh
```
